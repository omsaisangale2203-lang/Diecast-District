# 🚗 Diecast District
### Collect • Explore • Learn • Belong

**Diecast District** is a digital platform designed for diecast car collectors. It brings brand exploration, collector education, collection management and buying awareness together in one place.

Our goal is to make diecast collecting easier to understand, organise and enjoy — especially for beginners.

---

## 🌟 About the Project

Diecast District is a frontend web development project built using **HTML, CSS and JavaScript**.

It provides collectors with a central place to:
- Explore popular diecast brands.
- Learn about scales, rarity, variants and model care.
- Organise their personal diecast collection.
- Understand market pricing and resale practices.
- Compare prices and record estimated collection values.

## ✨ Key Features

### 1. Explore Brands
Explore information and dedicated pages for 21 diecast brands, including Hot Wheels, Matchbox, Mini GT, Tomica, Kaido House and more.

### 2. Collector's Academy
Beginner-friendly educational guides covering:
- Understanding diecast scales.
- Rarity and variants.
- Storing and protecting diecast models.

### 3. My Garage
A personal collection management section where users can:
- Add their diecast cars.
- Upload photos or add image URLs.
- Record brand, model, scale and purchase price.
- Search and filter their collection.
- View individual car details.

### 4. Collection Value Dashboard
Track:
- Total purchase spend.
- Saved estimated market value.
- Difference between purchase spend and estimated value.
- Number of cars with recorded valuations.

### 5. Market Watch
Educational content about:
- MRP, retail pricing and resale pricing.
- Scalping and artificial hype.
- Scam awareness.
- Smarter buying practices.

### 6. DD Deal Check
A guided price-comparison tool that helps collectors assess whether a listed price appears to be a good deal, fair deal or overpriced based on the comparison information entered.

### 7. Market Valuation
Record comparable sale prices for individual models, calculate a median estimate and save the valuation to My Garage.

## 🎯 What Makes Diecast District Different?

Diecast District is not just a diecast car catalogue. It combines:

- **Discovery:** Explore different diecast brands.
- **Education:** Learn about collecting.
- **Organisation:** Maintain a personal digital Garage.
- **Buying Awareness:** Understand pricing and common marketplace risks.
- **Value Tracking:** Record and compare collection values.

It aims to support the complete collector journey in one platform.

## 🔮 Future Scope

Potential future improvements include:
- User accounts and cloud-based collection storage.
- Shared community garages.
- Collector discussions and Q&A.
- Photo-assisted model identification.
- Integration with reliable live market-data sources.
- Advanced collection analytics.

## ⚠️ Current Project Scope

This version is frontend-only. Garage information is stored in browser Local Storage, so collections are not synchronised between devices.

Market valuations depend on comparable prices entered by the user. The website does not currently fetch or verify live marketplace sales automatically.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.htm`.
4. Run it using the Live Server extension.
